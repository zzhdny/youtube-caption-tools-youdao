# YouTube 字幕取词·有道词典（Chrome/Edge 扩展）

与《YouTube 字幕选词助手》（`youtube-caption-tools`）同源的姊妹扩展：**以有道词典为主导**——拖选/双击字幕一律弹出本扩展的有道弹窗（不交给欧陆词典等外部划词插件），并可直接把单词**收藏进你自己的有道生词本**。

| 功能 | 说明 | 状态 |
|---|---|---|
| 拖选字幕 → 有道翻译 | 按住拖选单词/短语/整句 → 弹窗显示有道翻译（短语、整句均可） | ✅ |
| 双击字幕单词 → 有道词典释义 | 音标（美/英）+ 🔊有道真人发音 + 词典释义（词性 + 释义）+ 词形变化 | ✅ |
| **一键收藏有道生词本** | 弹窗内 **「＋ 收藏到有道生词本」**，需已在浏览器登录 dict.youdao.com | ✅ |
| 沉浸式翻译「仅英文」开关 | 与第一扩展完全一致（右上角开关，隐藏中文行/整体隐藏+原生 CC） | ✅ |

## 与第一扩展的差异

- **取词路径**：第一扩展 v1.3.0+ 的拖选会把原生选区交给欧陆词典等外部划词插件；本扩展**全部收回**——拖选/双击都弹本扩展弹窗，用高亮（CSS Highlight API）而非原生选区，不会触发其他划词插件，也不会叠两个框
- **数据源**：有道词典 `dict.youdao.com/jsonapi_s`（词典释义、美/英音标、dictvoice 真人发音）优先，Google/MyMemory 仅作兜底；无密钥
- **收藏**：弹窗底部大按钮「＋ 收藏到有道生词本」，通过扩展后台复用浏览器已登录 Cookie 调用网页版生词本接口（`wordbook/ajax?action=addword`），不会索要密码；未登录时按钮下方提示
- 无「双击取词模式」开关（不需要，本扩展不依赖外部词典）

## 安装（Chrome / Edge 通用）

1. 地址栏输入 `edge://extensions`（Chrome 为 `chrome://extensions`）
2. 打开右上角 **开发者模式**
3. 点击 **加载已解压的扩展程序**，选择本目录（`youtube-caption-tools-youdao`）
4. **先在浏览器登录一次 dict.youdao.com**（收藏生词本用），然后打开任意 YouTube 视频页

## 使用

- **拖选**字幕里的单词/短语/整句 → 弹窗显示有道翻译（沉浸式翻译覆盖层内的字同样有效）
- **双击**字幕单词 → 音标 + 有道发音 + 词典释义 + 词形；点 **「＋ 收藏到有道生词本」** 收藏
- 🔊 按钮有道真人发音（美音优先），失败时自动退回本地语音合成
- 播放器右上角「字幕：双语 ⇄ 仅英文」开关与第一扩展一致
- `Esc`、**播放控制键**（空格、←/→/↑/↓、J/L/K、数字 0-9、M/F/T/I/C/N/P 等）或点击字幕以外区域均可关闭弹窗——按键同时照常执行 YouTube 的暂停/快进，不会被拦截；在输入框里打字时按键不关弹窗

## 注意

- 收藏生词本要求浏览器已登录 `dict.youdao.com`（网页版登录态）；未登录会提示「收藏失败：请先在浏览器登录」
- 有道接口在大陆网络直连可用，无需代理；Google 兜底源在大陆网络下可能需要代理（不影响有道主源）
- 两个扩展（本扩展与第一扩展）**同时启用会互相弹窗**——建议只开其中一个，或关闭其中一个的取词范围

## 目录结构

```
youtube-caption-tools-youdao/
├── manifest.json          # MV3 清单（host_permissions 含 dict.youdao.com）
├── content-main.js        # MAIN world：强制 open shadow root（同第一扩展）
├── content.js             # 核心逻辑：取词/拖选/有道弹窗/收藏/仅英文开关
├── background.js          # Service Worker：有道查词 + 兜底翻译 + 生词本收藏
├── content.css            # 解除字幕 user-select 限制 + 高亮样式
├── icons/
└── test/
    └── test.html          # 本地模拟页（py -3.12 -m http.server 8001 后访问 /test/test.html）
```
